# 11. Encapsulation (Инкапсуляция)

Домашнее задание по теме инкапсуляции в C#.

## Что сделано
- Класс `TravelCard`: поля `private`, доступ через свойства только для чтения
- Методы `TopUp`, `Pay` и приватный `HasEnoughBalance`
- Проверки в конструкторе, исключение `ArgumentOutOfRangeException`

## Как запустить
```
dotnet run
```
